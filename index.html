Beginner Friendly Walkthrough

Put This App on Your Android Phone & GitHub

Never used GitHub before? No problem. You don't need any coding tools—just a free account and 3 minutes.

Part 1: Host on GitHub for Free

Creates a permanent web link for your phone

  1. 1
    Download the App File Click the orange "Download index.html File" button above. It saves this entire app as a single file named index.html.
  2. 2
    Create a Free GitHub Account & Repository Go to github.com and sign up. Click the "+" icon in the top-right corner and select "New repository".
    • Under Repository name, type ballistics-app
    • Make sure Public is selected
    • Check the box that says "Add a README file"
    • Click the green "Create repository" button at the bottom
  3. 3
    Upload Your index.html File Inside your new repository page, click the "Add file" button near the top right, then click "Upload files". Drag and drop your downloaded index.html file into the box, then click the green "Commit changes" button at the bottom.
  4. 4
    Turn On "GitHub Pages" (Makes it a Live App!)
    • Click "Settings" (the gear icon at the top of your repository)
    • On the left sidebar menu, click "Pages"
    • Under "Branch", change the dropdown from None to main, then click Save
    • Wait about 60 seconds and refresh that page—GitHub will show your live link: https://your-username.github.io/ballistics-app/

Part 2: Install on Your Android Phone

Works 100% offline in the field or at the range

Why GitHub Pages + Chrome is Best:

When you open your GitHub Pages link in Google Chrome on Android, Android recognizes the embedded PWA manifest in this code and installs it as a real home-screen app that works with Airplane Mode ON.

  1. 1
    Open Your GitHub Link in Android Chrome Type your your-username.github.io/ballistics-app link into Chrome on your Android phone.
  2. 2
    Tap "Add to Home screen" or "Install App" Tap the three dots menu (⋮) in the top-right corner of Chrome and select "Add to Home screen" (or "Install app").
  3. 3
    Launch from Your Home Screen! A custom crosshair app icon named Ballistics will appear on your phone's home screen. Open it anytime—even with zero cell service in the woods!
